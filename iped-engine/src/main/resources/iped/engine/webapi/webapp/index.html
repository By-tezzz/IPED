Query syntax

Queries use the Lucene syntax IPED uses in its desktop interface.

  • bank statement — items containing both words
  • "bank statement" — exact phrase; also use quotes for anything with @, : or ., such as an email address
  • name:photo* — by property, wildcards allowed
  • ext:jpg or contentType:image/jpeg — by file type
  • size:[100000 TO *] — numeric range
  • modified:[2020-01-01 TO 2020-12-31] — date range
  • category:"Image Files" && deleted:true — combined with &&, ||, !
  • hash:d41d8cd98f00b204e9800998ecf8427e — by hash
